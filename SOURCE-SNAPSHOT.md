# Public source snapshot

This curated source export was prepared on 2026-09-28 from Steward source revision `c0516c5`, with the paper-style public landing page and connected onboarding layout, public documentation, licensing and banner added afterward. It contains a current-dated snapshot of source, tests and local tooling. It does not transplant or backdate the private repository's commit history.

Private staging logs, deployment records, environment secrets, and historical testnet fixtures are excluded. Five optional scripts that could run only with those withheld fixtures are excluded too. The local app, contract suite, build, API tests and CI configuration are included. See [implementation status](docs/implementation/IMPLEMENTATION-STATUS.md) for the scope of what has been exercised.

Before creating the public repository, verify the exact file inventory and GitHub account again. The publisher should make the first commit with the actual publication date and their verified signing identity, then retain a signed release record outside GitHub. The [setup guide](GITHUB-SETUP.md) describes the account and branch safeguards.
